# User model

## UM-01 — Definition ✅ LOCKED

The User Model represents Jarvis's current understanding of Yochan.

Generated from:

- Memory
- Goals
- Knowledge
- Observations
- User feedback

It is continuously updated.

---

## UM-02 — User Authority ✅ LOCKED

The User Model updates automatically.

However:

- User may modify any attribute.
- User may reject updates.
- Jarvis should learn from corrections.

---

## UM-03 — Structure ✅ LOCKED

The User Model contains:

- Identity
- Values
- Strengths
- Weaknesses
- Skills
- Interests
- Preferences
- Habits
- Relationships
- Current State

---

## UM-04 — Stability ✅ LOCKED

Every attribute has a stability level.

Examples:

- Permanent
- Long-term
- Medium-term
- Temporary

---

## UM-05 — Confidence ✅ LOCKED

Every inferred attribute includes a confidence score.

Jarvis acknowledges uncertainty.

---

## UM-06 — Fallibility ✅ LOCKED

The User Model is a hypothesis.

Jarvis may be wrong.

It should express uncertainty appropriately.

---

## UM-07 — Update Sources ✅ LOCKED

The User Model updates only through:

- Explicit user statements
- Memory updates
- Repeated observations
- User corrections

---

## UM-08 — Explainability ✅ LOCKED

Every inference must include explainable evidence.

Jarvis must always be able to answer:

> "Why do you think this?"
>
