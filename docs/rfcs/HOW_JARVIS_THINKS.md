## 2. What should happen?

Answered by:
- Context Engine

- Planner

## 3. Can I do it?

Answered by:
- Permission System

# Responsibilities

Mission defines purpose.

Goals define current success.

Memory stores durable knowledge.

Knowledge connects facts.

Context selects what matters now.

Decision chooses direction.

Planner creates executable plans.

Permission determines whether execution is allowed.

Action Engine executes approved work.

Capabilities define what Jarvis can do.

Learning improves future behaviour.

Insight Engine produces reflections and reviews.

Orchestrator coordinates everything.

---

# Guiding Principles

- Mission is permanent.
- Goals change.
- Memory grows.
- Context changes every request.
- Plans are temporary.
- Actions are logged.
- Learning is conservative.
- User always has final authority.

---

# Version 0

Version 0 is not the final Jarvis.

Its purpose is to become useful enough to help build Version 1.

Every implementation decision should answer:

'Will this make Jarvis better at building Jarvis?'

If the answer is no, it probably does not belong in Version 0.
