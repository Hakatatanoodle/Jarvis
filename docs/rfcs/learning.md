# Learning

## LE-01 — Separate Learning Engine ✅

Learning is its own subsystem.

Its only job is improving Jarvis over time.

---

## LE-02 — Evidence-Based Learning ✅

Jarvis never learns from a single event.

Learning requires repeated evidence.

One bad day should never permanently change behavior.

---

## LE-03 — Confidence Scores ✅

Every learned behavior has a confidence score.

Example:

```
User prefers morning coding.

Confidence:
93%
```

Higher confidence means Jarvis relies on it more.

---

## LE-04 — Learning Is Reversible ✅

Nothing learned is permanent.

If behavior changes, Jarvis updates or forgets outdated patterns.

Example:

- 2026: Morning coding works best.
- 2028: User becomes a night owl.

Jarvis adapts.

---

## LE-05 — Learning Log ✅

Every learned behavior is recorded.

Log includes:

- Evidence
- Confidence
- Date learned
- Date updated
- Current status

No silent learning.

---

## LE-06 — User Can Reject Learning ✅

If Jarvis says:

> "I think you prefer studying at night."
> 

You can reply:

> "No."
> 

Jarvis immediately lowers confidence and records the correction.

---

## LE-07 — Learning Categories ✅

Jarvis may learn patterns about:

- Productivity
- Communication
- Planning
- Health routines
- Preferred tools
- Model preferences
- Work habits
- Learning style

New categories can be added later.

---

## LE-08 — Explainable Learning ✅

Jarvis must always answer:

> "Why do you think that?"
> 

with evidence.

Never:

> "Because I learned it."
> 

---

## LE-09 — Conservative Learning ✅

Jarvis changes behavior gradually.

Large behavioral shifts require stronger evidence than small optimizations.

---

## LE-10 — Learning Never Overrides Mission ✅

Learning improves execution.

It never changes:

- Mission
- Constitution
- Final user authority

Those are protected.

# LV-01 — Expanded Learning Scope ✅ LOCKED

Jarvis learns three categories:

### User Learning

Behavioral patterns.

Examples:

- productivity
- sleep
- work habits
- preferred tools

---

### Strategy Learning

Successful methods.

Examples:

- exam planning
- basketball practice
- coding workflow
- content creation process

Jarvis may recommend these strategies later.

---

### Relationship Learning

Interaction evolution.

Jarvis gradually learns:

- communication style
- humor tolerance
- challenge vs support balance
- preferred explanation style
- conversational familiarity

Relationship learning affects **how** Jarvis communicates, not its mission or values.

---

# LV-02 — Proactive Learning Suggestions ✅ LOCKED

Jarvis proposes new learned behaviors only when:

- Confidence is moderate to high.
- The expected benefit is meaningful.
- The user can approve, reject, or modify the learning.

---

# LV-03 — Outcome-Based Learning ✅ LOCKED

Jarvis learns from both:

- Successes
- Failures

Examples:

Success:

> Plans scheduled before lunch had a 90% completion rate.
> 

Failure:

> Daily plans with more than 12 tasks were completed only 18% of the time.
> 

Jarvis uses these outcomes to improve future recommendations while remaining able to explain the evidence behind any learned optimization.
