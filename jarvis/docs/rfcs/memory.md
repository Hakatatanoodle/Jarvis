# Memory

## M-01 — Archive vs Memory ✅ LOCKED

Jarvis distinguishes between **Archive** and **Memory**.

**Archive**

- Stores everything.
- Every conversation, document, event, interaction, etc.
- Acts as historical storage.

**Memory**

- Stores distilled, meaningful information extracted from the archive.
- Used for fast retrieval and reasoning.
- Represents understanding rather than raw history.

**Principle**

> History is everything.
> 
> 
> Memory is what matters.
> 

---

## M-02 — Memory Creation ✅ LOCKED

Memories can be created in three ways.

### Rule-Based

Always store:

- Long-term goals
- Active projects
- Important people
- Preferences
- Permissions
- Recurring routines
- Major life events

---

### AI-Based

Jarvis proposes memories based on significance.

Examples:

- Lessons learned
- Behavioral patterns
- Important conversations
- Insights

Each AI-created memory stores:

- Confidence
- Timestamp
- Source
- Reason

---

### User-Controlled

User has highest authority.

Commands include:

- Remember this
- Never forget this
- Forget this
- Update this memory
- Merge memories
- Do not remember this

---

## M-03 — Memory Versioning ✅ LOCKED

Memories are never overwritten.

Instead:

- Previous version is archived.
- New version becomes active.
- Evolution is preserved.

Jarvis should understand how memories changed over time.
